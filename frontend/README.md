# Club Booking frontend

Nuxt 4, Vue 3 va TypeScript asosidagi customer web frontend.

## Ishga tushirish

```powershell
npm install
npm run dev
```

Frontend: `http://127.0.0.1:3000`

Django API manzili `.env` orqali sozlanadi:

```env
NUXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000/api/v1
```

## Tekshiruvlar

```powershell
npm run typecheck
npm run lint
npm run build
```
